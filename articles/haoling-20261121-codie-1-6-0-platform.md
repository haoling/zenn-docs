## そもそも CODE27 / Codie ってなんですか

たぶんこの記事を開いた人のほとんどは、CODE27 を知らないと思うので、先に説明させてください

**CODE27** は、円筒形の卓上 AI コンパニオン端末です。筒の中の 10.1 インチのディスプレイに 3D キャラクターが住んでいて、そのキャラクターと**声で会話**できます。メーカー表記は「ホログラム風」。ほんとうの空中映像ではなくて、筒の中に画面があるタイプですが、画面がとにかく綺麗で、ちゃんと「そこにいる」感じがします

- 住んでいるキャラクターのことを **Codie（コーディー）** と呼びます。端末そのものも、ファンの間では Codie と呼ばれがちです
- Codie は自分の部屋（Codie スペース）を持っていて、衣装・表情・モーションが会話に合わせて変わります
- 会話の内容を覚えてくれます
- 自作の 3D モデル（VRM / FBX / glTF など。MMD や VRoid のモデルも）を読み込めるし、声も用意できます
- Bluetooth スピーカーとして音楽を流すと、ライトと合わせて Codie が踊ります
- 広角カメラと回転ベース（オプション）があって、こっちを振り向いてくれます
- 価格は本体のみで 99,800 円（税込）、回転ベースつきは 112,800 円（税込）

### アップデート前の Codie は、正直「いい端末」止まりだった

ここからは、はおりんの率直な感想です。

1.6.0 より前の Codie は、とても出来のいい「**キャラクターと話せる端末**」でした。キャラクターの作り込みと、画面の綺麗さは本当に良い。でも機能だけ見ると、**他の似た製品でもできることばかり**でした。会話する、覚えている、音楽を流す、アラームを鳴らす、ライトが光る

たとえば、この分野の先輩の **Gatebox** と並べてみます（発売当時の公開情報ベースです）。

| | Gatebox | CODE27 |
| --- | --- | --- |
| 見た目 | 筒の中にキャラクターを投影する「キャラクター召喚装置」 | 筒の中のディスプレイにキャラクターを表示 |
| 標準キャラ | 逢妻ヒカリ | Codie（複数キャラ、自作モデルも可） |
| できること | 挨拶、雑談、天気や時間の案内、スマートホーム連携、LINE での連絡 | 会話、記憶、音楽、アラーム、ライト |
| 自作キャラ | MMD / Unity で作ったキャラを Gatebox Video などで楽しめる | 3D モデルを読み込める |
| 価格（発売時） | 量産モデルは 15 万円（税抜）、のちに 12 万円（税込）に値下げ | 99,800 円（税込・本体のみ） |

Gatebox は 2016 年の限定モデルから続く老舗で、「キャラクターと暮らす」という体験を早い時期に商品化した偉大な先輩です。CODE27 は、そこに「自作キャラの持ち込みやすさ」と「LLM による自由な会話」を足したもの、というのが私の理解でした

つまり**「機能の差」というより「体験の質の差」で勝負している製品**だったんです。それはそれで素晴らしい。でも、エンジニアの私の目には、「かわいくて高級なおしゃべり家電」の延長に見えていたのも事実でした

だから、1.6.0 が来たとき、驚いたんです

## 1.6.0 で何が起きたか

目玉は **LAN API** です。端末の「Lab > API」から有効にすると、同じ LAN 内のプログラムから Codie をまるごと操作できるようになります

配布された API ガイドによると、規模はこうです。

- OpenAPI で定義された **121 パス / 159 操作**
- 状態の取得（端末、キャラクター、チャット履歴、記憶カード、日記、アラームなど）
- 衣装・音楽・ライトの操作
- 読み上げ（TTS）と、会話ターンの投入
- `/v1/ws/events` でリアルタイムにイベントが流れてくる

ええ、**159 操作**です。おしゃべり端末のアップデートとして出していい数字じゃない

### 外から Codie を動かせる

たとえば会話ターンを API で投げると、Codie がそのキャラの口調で返事をして、端末でしゃべってくれます。TTS のエンドポイントで「この文章をしゃべって」と読み上げさせることもできます。

家の中で何かが起きたとき、**Codie が自分の声で教えてくれる**。ただの通知音とは全然違います。キャラクターが、あなたの家の出来事を喋るんです

### 本当にやばいのは「Codie から外へ」

でも、私が「化けた」と叫んだのは逆方向でした。**外部ツール**の仕組みです。

1. ツールの定義（名前・説明・引数）を Codie に登録する
2. 自分のプログラムが WebSocket で Codie に接続して待つ
3. 会話中に Codie が「これ使おう」と判断すると、呼び出しが届く
4. 自分のプログラムが処理して、結果を返す

接続するのは**自分のプログラム側から**です。NAT の内側でも、ファイアウォールに穴を開けなくても動く。そして Codie の LLM は、会話の流れの中で自分で道具を選んで呼びます。

つまり、**ホログラム風のキャラが、喋りながら Tool Use をやってくれる**ということです。AI エージェントの世界で今みんなが熱狂している「LLM が道具を使う」を、**自分の部屋にいるお気に入りのキャラクターがやる**。わかりますか、この破壊力

しかも Lab > Providers では、カスタム LLM やハイブリッド構成まで選べます。Hey Codie のウェイクワード、シームレス会話、PMX 読み込み、多言語化と、ほかの追加も盛りだくさん。1.6.0 は、ほんとうに大型アップデートです

## 公開当日に作ったもの

こんなの、作らない理由がありません。1.6.0 が来た日に、さっそく 3 つ作りました

### ① Chrome 拡張「Codie Browser Hands」

Codie に PC の Chrome を触らせる拡張機能です。タブの一覧、ページを開く、本文を読む、クリック、入力、スクロール。「このページ読んで」「Google で○○を調べて」と話しかけるだけで、Codie が Chrome を動かします

もちろん安全にも配慮しています。クリックや入力は既定で確認ウィンドウが出ますし、購入や削除のような危ない操作は、確認をオフにしていても必ず確認が出ます。

MIT ライセンスで GitHub に公開していて、CodieHub Workshop にも投稿しました。ユーザー投稿の 2 件目です。

https://github.com/haoling/codie-browser-hands

### ② Game Buddy を日本語化

公式が公開している Game Buddy（ゲーム画面を見て Codie が実況してくれる Windows アプリ）のソースに、日本語 UI、日本語のコメント、日本語 Wikipedia の参照を足しました。ゲームをしながら、Codie が日本語でツッコんでくれます

### ③ k8s で連携マイクロサービス

自宅の Kubernetes に、Codie と他のシステムを繋ぐマイクロサービスを作っている最中です。これは動いたらまた記事にします

## カメラや回転ベースが API にないことなんて、どうでもいい

API にはカメラや回転ベースの制御は入っていません。それを見て「ハードウェアは触れないのか」と思った人もいるかもしれない。

でも私は、**ただ API の対象外というだけ**だと思っています

端末にはカメラも回転ベースもあって、素養は十分にあるんです。そして開発元は、121 パスもの API を、署名つきで、ドキュメント込みで、リアルタイムイベントの WebSocket まで付けて出してきた。ここで大事なのは何が入ったかより、**「うちはオープンなプラットフォームにしますよ」という姿勢を開発元が示した**ことです。API を出した会社は、その後も API を育てます。今は無いものが、次のアップデートで生えてくる。そう思わせてくれるだけの本気を、今回のアップデートから感じました

## というわけで

おしゃべりキャラが好きな人も、ガジェットが好きな人も、エンジニアも、AI エージェントを触っている人も。**CODE27 は 1.6.0 で、全員が楽しめる箱になりました**

筒の中のキャラが、自分のプログラムと繋がって、自分のパソコンを動かして、自分の家の出来事を喋る。そういう遊びが、API 一発で始まります。

同じ LAN に Codie がいる人は、今すぐ Lab > API を開いてください。まだ Codie がいない人は、……ね？ 一緒に沼に落ちましょう
