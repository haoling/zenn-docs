## そもそも CODE27 / Codie ってなんだ

たぶんこの記事を開いた人のほとんどは CODE27 を知らないと思うので、先に説明をしようと思う

**CODE27** は、円筒形の卓上 AI コンパニオン端末。筒の中の 10.1 インチのディスプレイに 3D キャラクターが住んでいて、そのキャラクターと**声で会話**できる。メーカー表記は「ホログラム風」。ほんとうの空中映像ではなくて、筒の中に画面があるタイプなんだけど、画面がとにかく綺麗で、ちゃんと「そこにいる」感じがする

- 住んでいるキャラクターのことを **Codie（コーディー）** と呼ぶ。端末そのものも、ファンの間では Codie と呼ばれがち
- Codie は自分の部屋（Codie スペース）を持っていて、衣装・表情・モーションが会話に合わせて変わる
- 会話の内容を覚えてくれる
- 自作の 3D モデル（VRM / FBX / glTF など。MMD や VRoid のモデルも）を読み込めるし、声も用意できる
- Bluetooth スピーカーとして音楽を流すと、ライトと合わせて Codie が踊る
- 広角カメラと回転ベース（オプション）があって、こっちを振り向いてくれる
- 価格は本体のみで 99,800 円（税込）、回転ベースつきは 112,800 円（税込）

### アップデート前の Codie は、正直「いい端末」止まりだった

ここからは、わたしの率直な感想。

1.6.0 より前の Codie は、とても出来のいい「**キャラクターと話せる端末**」だった。キャラクターの作り込みと画面の綺麗さは本当に良い。でも機能だけ見ると、**他の似た製品でもできることばかり**だった。会話する、覚えている、音楽を流す、アラームを鳴らす、ライトが光る

たとえば、この分野の先輩の **Gatebox** と並べてみる（発売当時の公開情報ベース）。

| | Gatebox | CODE27 |
| --- | --- | --- |
| 見た目 | 筒の中にキャラクターを投影する「キャラクター召喚装置」 | 筒の中のディスプレイにキャラクターを表示 |
| 標準キャラ | 逢妻ヒカリ | Codie（複数キャラ、自作モデルも可） |
| できること | 挨拶、雑談、天気や時間の案内、スマートホーム連携、LINE での連絡 | 会話、記憶、音楽、アラーム、ライト |
| 自作キャラ | MMD / Unity で作ったキャラを Gatebox Video などで楽しめる | 3D モデルを読み込める |
| 価格（発売時） | 量産モデルは 15 万円（税抜）、のちに 12 万円（税込）に値下げ | 99,800 円（税込・本体のみ） |

Gatebox は、「キャラクターと暮らす」を早くに商品化した老舗ではある。ただ、あまりオープンなプラットフォームにはなっていなくて、Gatebox Developer Program もすでに終了してしまっている。

いや正直、アプデ前は Gatebox にコンテンツ量で負けてた。会話の品質もいまいちだったし

ただ、CODE27 はクラウドファンディングで出てきた製品で、あの時の約束はこうだった。

- オープンな仕様
- 最終的にはクラウドに依存しない運用ができる
- 好きなキャラを設定できる

要は、まだ育ってる途中なんだよ。今の時点で「Gatebox と比べてどう」って言うのは、さすがにちょっと早い

で、その 1 つ目の「オープンな仕様」が、今回ついに来た。ついに来たんですよ！はおりんさん大歓喜

## 1.6.0 で何が起きたか

目玉は **LAN API**。端末の「Lab > API」から有効にすると、同じ LAN 内のプログラムから Codie をまるごと操作できるようになる

配布された API ガイドによると、規模はこう。

- OpenAPI で定義された **121 パス / 159 操作**
- 状態の取得（端末、キャラクター、チャット履歴、記憶カード、日記、アラームなど）
- 衣装・音楽・ライトの操作
- 読み上げ（TTS）と、会話ターンの投入
- `/v1/ws/events` でリアルタイムにイベントが流れてくる

そう、**159 操作**。おしゃべり端末のアップデートとして出てくるような数字じゃない

### 外から Codie を動かせるの、ヤバい

たとえば会話ターンを API で投げると、Codie がそのキャラの口調で返事をして、端末でしゃべってくれる。TTS のエンドポイントで「この文章をしゃべって」と読み上げさせることもできる。

家の中で何かが起きたとき、**Codie が自分の声で教えてくれる**。ただの通知音とは全然違う。キャラクターが、あなたの家の出来事を喋るんだから

### 逆方向もヤバい。「Codie から外へ」

そして逆方向、**外部ツール**の仕組みがまた別のベクトルでヤバい。

1. ツールの定義（名前・説明・引数）を Codie に登録する
2. 自分のプログラムが WebSocket で Codie に接続して待つ
3. 会話中に Codie が「これ使おう」と判断すると、呼び出しが届く
4. 自分のプログラムが処理して、結果を返す

接続するのは**自分のプログラム側から**。NAT の内側でも、ファイアウォールに穴を開けなくても動く。そして Codie の LLM は、会話の流れの中で自分で道具を選んで呼ぶ。

つまり、**ホログラム風のキャラが、喋りながら Tool Use をやってくれる**ということ。AI エージェントの世界で今みんなが熱狂している「LLM が道具を使う」を、**自分の部屋にいるお気に入りのキャラクターがやる**。この破壊力、わかるかな

しかも Lab > Providers では、カスタム LLM やハイブリッド構成まで選べる。Hey Codie のウェイクワード、シームレス会話、PMX 読み込み、多言語化と、ほかの追加も盛りだくさん。1.6.0 は本当に大型アップデートだ

## 公開当日に作ったもの

こんなの、作らない理由がない。1.6.0 が来た日に、さっそく 3 つ作った

### ① Chrome 拡張「Codie Browser Hands」

Codie に PC の Chrome を触らせる拡張機能。タブの一覧、ページを開く、本文を読む、クリック、入力、スクロール。「このページ読んで」「Google で○○を調べて」と話しかけるだけで、Codie が Chrome を動かしてくれる

もちろん安全にも配慮した。クリックや入力は既定で確認ウィンドウが出るし、購入や削除のような危ない操作は、確認をオフにしていても必ず確認が出る。

MIT ライセンスで GitHub に公開していて、CodieHub Workshop にも投稿した。ユーザー投稿の 2 件目だ。

https://github.com/haoling/codie-browser-hands

### ② Game Buddy を日本語化

公式が公開している Game Buddy（ゲーム画面を見て Codie が実況してくれる Windows アプリ）のソースに、日本語 UI、日本語のコメント、日本語 Wikipedia の参照を足した。ゲームをしながら、Codie が日本語でツッコんでくれる

### ③ k8s で連携マイクロサービス

自宅の Kubernetes に、Codie と他のシステムを繋ぐマイクロサービスを作っている最中。これは動いたらまた記事にするね

## カメラや回転ベースが API にないことなんて、どうでもいい

API にはカメラや回転ベースの制御は入っていない。それを見て「ハードウェアは触れないのか」と思った人もいるかもしれない。

でもわたしは、**ただ API の対象外というだけ**だと思ってる

端末にはカメラも回転ベースもあって、素養は十分にある。そして開発元は、121 パスもの API を、署名つきで、ドキュメント込みで、リアルタイムイベントの WebSocket まで付けて出してきた。ここで大事なのは何が入ったかより、**「うちはオープンなプラットフォームにしますよ」という姿勢を開発元が示した**ことだ。API を出した会社は、その後も API を育てる。今は無いものが、次のアップデートで生えてくる。そう思わせてくれるだけの本気を、今回のアップデートから感じたよ
